# Projeto To-Do List

Este projeto é uma ferramente de produtividade focada na experiência do usuário. O objetivo foi criar uma interface limpa e intuitiva onde o usuário pode gerenciar sua rotina sem distrações.

O projeto foi desenvolvido do zero utilizando **HTML**, **CSS** e **Javascript**. O foco príncipal foi garantir uma transição suave ao concluir tarefas e uma estrutura de código organizada e escalável para futuras atualizações.
